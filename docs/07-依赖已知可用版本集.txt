# 07 · 依赖「已知可用版本集」（R5-收口 ②）

**用途**：`pip freeze` 的快照。`pipeline/requirements.txt` **未锁版本**，
而 ARC 在 `agents/runtime/factory.py:10-11` **模块级**导入了 deepagents 的**私有路径**：

    from deepagents._models import get_model_provider
    from deepagents.backends.filesystem import _raise_if_symlink_loop

私有路径没有兼容性承诺 → 平台装到漂移后的 deepagents 时，**保底包会在 import 阶段直接炸**。
这份文件是"当时确实能跑"的证据：出问题先拿它比对，必要时回钉。

**采集环境**：2026-09-20，工作区根 `.venv`（Python 3.13.11），
装的是 `pipeline/requirements.txt`（13 个直接依赖，这里 69 行含全部传递依赖）。

**采集时验证过的**（全部 exit 0）：
1. `import deepagents, langchain_openai` ✅
2. ARC 入口 `repos/agentic-requirement-compiler/src/main.py` 的完整 import 图 ✅
3. `arc doctor` → `✓ Configuration is valid` ✅（需显式加载工作区 `.env`；ARC 只找**当前目录**的 `.env`）

**关键版本**（漂移时先看这几个）：
- `deepagents==0.7.15`  ← **私有路径风险就在它身上**
- `langchain-openai==1.6.2` / `langchain==1.4.2` / `langchain-core==1.6.3`
- `openai==3.16.2` / `pydantic==2.13.5` / `tiktoken==0.13.0`

**复现**：
```bash
python -m venv .venv && ./.venv/Scripts/python.exe -m pip install -r pipeline/requirements.txt
./.venv/Scripts/python.exe -m pip freeze > docs/07-依赖已知可用版本集.txt
```

⚠️ **仍未做的**（R5-收口 ③）：**`arc compile` 从未真正跑过**（要真实 LLM 调用）。
在它跑通之前，"保底包能上榜"仍只是假设。
